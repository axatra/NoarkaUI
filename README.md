# Noarka UI
Welcome to the official repository for **Noarka UI**, a modern React component library built on top of **Base UI** and designed to provide a consistent, accessible, and polished interface across Noarka products.

Noarka UI powers the shared UI experience across the Noarka ecosystem, providing reusable components and design patterns for building consistent product interfaces.

> **⚠️ Development Notice**
>
> Noarka UI and its documentation website are currently under active development. Expect frequent updates, improvements, and changes as the project continues to evolve.
